# SAM AI Task 3 – Object Detection

## 📌 Project Overview

This project is an AI-based Object Detection application developed as part of **SAM AI Task 3**.

The application uses a pretrained **YOLO11n ONNX model** to detect common objects in an uploaded image. It identifies objects, draws bounding boxes around them, and displays confidence scores.

## 🚀 Features

- Upload JPG, JPEG, and PNG images
- Detect multiple objects in an image
- Draw bounding boxes around detected objects
- Display object names
- Display confidence scores
- Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenCV
- NumPy
- ONNX Runtime
- YOLO11n
- COCO Dataset Classes
